## 范围

- 将协议、TUI 状态、Thread 恢复与 Run 请求从仅有 `primary_profile` 扩展为 ADR 中的 `ThreadExecutionSelection`：root Agent/根模型选择和 `agentModelOverrides`。保持旧 minor 与 ZC-078 root-only 请求兼容，不让缺失字段改变现有行为。
- 扩展 `/model` 解析与 Picker：`/model <profile>` 仍选择 root；`/model agent:<id> <profile>` 只允许选择当前 root Policy 可以派发、catalog 已登记且 Profile 可用的 Agent。`reset` 分别清除 root 或目标 Agent 覆盖。活动 Run、审批、问答、取消收敛和压缩期间仍禁用选择。
- Subagent 模型按“合法 spawn override → Thread agent override → AgentDefinition 默认”解析；根模型覆盖不得作为 Subagent 回退。所有实际 Profile、能力和模型来源必须由服务端校验并写入 RunExecutionBinding，客户端不得乐观伪造 actual 状态。
- 定义脱敏 Agent catalog/执行 binding 查询或事件投影，使状态栏、`/status` 与时间线能显示 selected 与 actual；每个 Subagent 开始、结束或失败的展示必须带 Agent ID、execution ID 与实际模型摘要，不传输 Prompt、凭据、完整 endpoint 或未授权任务正文。

## 非范围

- 不允许 `/model` 修改 AgentDefinition 默认模型、ExecutionPolicy、Provider、endpoint、凭据或 managed lock。
- 不提供任意 Agent/模型组合：不在当前 root Policy `allowedAgents` 中、catalog 不存在、Profile 不可用或能力不满足的目标必须拒绝。
- 不实现运行中热切换、成本自动路由、模型市场、固定 Workflow/Team 或 Agent 在线编辑。

## 验收清单

- Root override、Agent override、spawn override 与 Agent 默认模型按 ADR 优先级解析；根 `/model pro` 不改变 Explorer/Reviewer 的默认模型，运行中修改不影响已启动 Run 的 selection snapshot。
- 无效 Agent/Profile、未授权 delegation、能力不足、旧 minor、Picker 取消、持久化/恢复失败和同一 run 的重试均不污染现有选择或历史 binding。
- TUI 在空闲、运行、恢复和历史查看中明确区分 Selected 与 Actual；root/subagent 实际模型、来源和失败状态来自服务端 RunExecutionBinding，窄终端与焦点回归通过。
- Python 覆盖选择解析、spawn 覆盖、RunBinding；TypeScript 覆盖命令、Picker、状态栏、时间线和协议协商；完成 protocol、typecheck、test 与 project 检查。
