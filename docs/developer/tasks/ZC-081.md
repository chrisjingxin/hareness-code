## 范围

- 新增 ADR `0001-agent-domain-model.md`，将以下六个对象定为唯一核心领域模型，并给出语言无关 JSON Schema/TypeScript/Python 伪类型、稳定 ID、引用约束、序列化边界和版本演进规则：

  ```text
  ProviderDefinition
          │
          ▼
     ModelProfile ──────┐
                          ▼
  ExecutionPolicyDefinition → AgentDefinition
                                  │
  ThreadExecutionSelection ───────┤ 运行时解析
                                  ▼
                         RunExecutionBinding
  ```

  `RunExecutionBinding.executions` 中的 `AgentExecutionBinding` 是嵌套值对象，记录根/子执行的父子关系、实际模型、策略指纹、状态与时间；它不是第七个可配置对象。
- 固定字段唯一归属：Provider 持有 adapter、endpoint、凭据/安全 Header 引用；ModelProfile 持有 `provider_id`、模型 ID、reasoning、调用参数、能力与窗口；ExecutionPolicy 持有工具、文件、Shell、网络、隔离、审批与 delegation；AgentDefinition 持有身份、目的、Prompt/fragment 引用、输入输出契约、成功标准、默认 ModelProfile 与 Policy 引用；ThreadSelection 持有根 Agent 与可变模型覆盖；RunBinding 持有请求快照和实际执行事实。
- 固定可变性与解析规则：静态定义不可被 Thread/Run 修改；ThreadSelection 只影响未来 Run；单个 AgentExecutionBinding 启动后不可改变模型/策略；RunBinding 可在运行时追加 execution，终态后 sealed。`ResolvedAgentSpec` 仅是内部临时解析结果，不配置、不持久化、也不作为跨进程协议实体。
- 固定非对象与模式边界：Role/Persona 合并为 AgentDefinition 的任务与指令内容；Instruction Fragment 是 Agent 引用的文件资产；固定 Workflow/Team 是未来可选编排模式而非动态 delegation 主路径，不能成为当前 Model/Thread/Run 语义的前置条件。
- 定义现有兼容映射和分阶段迁移：当前 TOML `models.profiles.*` 先作为输入 adapter，物化 ModelProfile 及其 ProviderDefinition 投影，不在本任务改变 endpoint/API Key/`headers_env` 契约；当前 `harness_thread_model_bindings` 和 `harness_thread_runtime_profiles` 标记为 legacy 读取来源，未来由 RunExecutionBinding 取代其“当前选择”职责；RuntimeProfile 只引用实际静态定义的脱敏指纹，绝不携带 ThreadSelection、消息、Run ID 或凭据。
- 定义必需的模型选择优先级与错误语义：根 Agent 的 Thread primary override 仅覆盖根 Agent；动态子 Agent 后续仅允许合法 spawn override 覆盖其 AgentDefinition 默认模型；每个选择必须记录来源。无效引用、配置漂移、越权 Policy、循环引用和 legacy 无法恢复均 fail closed。

## 非范围

- 不实现新的 JSON/TOML 文件、SQLite 迁移、RPC、Picker、RuntimePool 改造、默认模型写入或动态 Subagent；本任务只产出经审查的架构契约和对现有实现的映射。
- 不将 Role、Persona、AgentWorkflow、Team、Mailbox、Instruction Fragment 或 ResolvedAgentSpec 升格为核心配置对象；未来如需独立生命周期，必须通过新的 ADR 显式修订本决策。
- 不改变当前用户可见的模型、执行、审批、Sandbox、凭据或项目配置可信行为。

## 验收清单

- ADR 包含对象关系图、每个对象的最小 schema、字段唯一归属表、生命周期/可变性表、模型选择优先级、Run 执行树语义、RuntimeProfile 边界、错误分类和敏感数据排除规则。
- ADR 明确给出当前 `Za38Config`、`ModelRouter`、`ThreadStore`、`RuntimeProfile`、`RuntimePool`、`RunContext` 与 TUI 状态到 canonical 对象的映射，并列出 ZC-078、ZC-080、ZC-015 各自允许修改的对象与存储边界。
- `ProviderDefinition` 与 `ModelProfile` 的拆分保持“连接到哪里”与“调用哪个模型”的边界，同时说明现有单个 TOML Profile 为什么可作为兼容输入 adapter；任何记录、DTO、指纹和示例均不包含 API Key、认证 Header、原始 endpoint、完整 Prompt 或工作区路径。
- 更新架构总览与配置架构中的对象术语和引用；`bun run docs:check`、`bun run tasks:check` 与 `git diff --check` 通过。
