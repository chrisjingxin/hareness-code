## 范围

- 提供 Plugin AgentDefinition 的脱敏只读目录，显示名称、目的摘要、默认模型、Policy 摘要、Plugin 来源，以及当前内置主 Agent 是否允许派发和不可用原因；不显示 Prompt 正文、凭据、endpoint 或未授权 Policy 细节。
- `/agent` 打开 SearchPicker，参数预填搜索，只用于查看可派发 Agent。主 Agent 始终由 Python 内置代码构建，当前 Thread 不保存 `rootAgentId`，确认目录项不改变后续 Run 的 root。
- 目录和可用性必须由 Plugin catalog、当前内置主 Agent 的 delegation Policy 与模型可用性共同校验；模型选择仍由 `/model` 管理，`/agent` 不改写根或子 Agent 的模型覆盖。

## 非范围

- 不实现根 Agent 选择、固定 Workflow、Agent Team、自由 Worker、运行中 Agent 热切换、Agent/Policy 在线编辑或自定义 Prompt 编辑。
- 不复制或显示动态 Subagent 的完整任务、交接正文或内部 Prompt。

## 验收清单

- 未安装 Plugin、非法 Plugin Agent、当前 Policy 不允许派发、模型/Policy 不可用和活动 Run 均有端到端回归；`main` 从不作为可选目录项出现。
- 详情与诊断不含模型凭据、完整系统 Prompt、内部任务正文或 handoff payload。
