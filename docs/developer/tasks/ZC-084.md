## 范围

- 定义内部 Canonical Message、Canonical Tool Call 与 Canonical Tool Result，并在 Checkpointer/历史读取和 Provider adapter 边界建立显式转换；它们是内部 DTO，不新增 Thread/Run 核心对象或开放原始 Provider payload。
- 为现有 OpenAI-compatible adapter 和 mock 的第二 Provider adapter 编写序列化/反序列化契约：保留有序文本、工具调用/结果、附件引用和必要的错误状态；禁止将签名、缓存控制、加密 reasoning、未知 opaque metadata 或 Provider 专有角色字段跨 Provider 传递。
- 明确无法安全转换时的 fail-closed 或可读降级语义，并在 TUI/诊断中只显示脱敏的兼容性说明；不得静默把当前模型配置或空消息伪装为历史。
- 将“新增独立 ProviderDefinition/ModelProfile catalog 或第二外部 Provider”设为本任务后的独立需求门槛；现有 TOML v1 adapter 与凭据来源在本任务不变。

## 非范围

- 不新增真实外部 Provider、Provider 市场、模型自动 fallback、消息全文导出或跨设备同步。
- 不修改 AgentDefinition、ExecutionPolicy、dynamic delegation 或模型选择优先级。

## 验收清单

- 两个 mock adapter 的跨模型续聊覆盖纯文本、多轮 tool call/result、失败工具结果、附件引用和被剥离私有 metadata；工具调用配对、消息顺序和 Thread 隔离不回归。
- 不兼容/损坏历史、未知 Provider 字段、缺失 Tool Result 与过大 payload 都有稳定错误或明确可读降级，且不会发送秘密、签名、完整 endpoint、Prompt 或工作区外路径。
- 历史转换不改变 RunExecutionBinding 记录的实际模型事实；Python provider/checkpoint 集成测试及用户/开发文档、项目检查通过。
