## 范围

把已验证的 stdio MCP 配置接入 `langchain-mcp-adapters`，建立会话所有权、工具过滤和 server 状态 DTO。

## 非范围

不实现 HTTP/SSE transport、OAuth、项目未信任配置的临时批准 UI 或 MCP 热重载。

## 验收清单

- [x] stdio server 的工具能注册、调用和在退出时清理（`close_all()` 释放连接）。
- [x] 启动超时、连接失败均有诊断且不阻塞 Agent 启动。
- [x] MCP 工具在 default/auto-edit 审批模式下需 HITL 审批，plan 模式拒绝，yolo 模式自动执行。
- [x] CLI 端 `/mcp` 可查看逐服务器连接状态和工具列表（`mcp.status` 协议方法）。
- [x] CLI 端 `/mcp add`/`/mcp remove` 支持运行时增删服务器（热连接/热断开）。

## 完成说明

通过 `.trae/specs/add-mcp-integration` 和 `.trae/specs/add-cli-mcp-management` 及 `.trae/specs/add-mcp-add-remove` 实施。核心实现：
- `mcp.py`: `McpConnectionManager` 管理连接生命周期，`connect_all()`/`close_all()`/`add_server()`/`remove_server()`
- `server.py`: `_connect_mcp_servers()` 在 initialize 时建立连接，`_handle_mcp_status`/`_handle_mcp_add`/`_handle_mcp_remove` 处理器
- `agent.py`: MCP 工具注入 Agent 图，参与审批注册和 schema 指纹
- `mcp_config_writer.py`: TOML 配置原子写入
- 协议：`mcp.status`/`mcp.add`/`mcp.remove` JSON-RPC 方法

## 已知简化

- 用户级配置默认信任，未经过 ZC-030 的指纹信任检查（ZC-030 尚未实现）。
- 无显式工具 allowlist/blocklist 过滤，靠审批模式（plan 拒绝 / default 需审批 / yolo 放行）间接控制。
