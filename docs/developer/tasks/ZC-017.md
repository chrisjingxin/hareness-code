## 范围

扩展 ZC-016 的 MCP session manager，使其管理 HTTP 与 SSE 连接并遵守 ZC-005 的信任决定。

## 非范围

不实现 OAuth、自动重连 UI、任意 URL 直连或用户自定义 TLS 绕过。

## 验收清单

- [x] HTTP 和 SSE 配置解析、连接构建有测试覆盖。
- [x] 认证头支持 `${VAR}` 环境变量插值，缺失时跳过服务器。
- [x] 连接失败不阻塞启动，错误状态可通过 `mcp.status` 查询。
- [x] `/mcp add <name> --url <url>` 和 `--sse` 支持从 CLI 添加远程服务器。
- [ ] mock HTTP/SSE MCP 服务器的 E2E 工具注册、调用和 cleanup 测试。
- [ ] HTTP/SSE 连接的会话清理验证（`close_all()` 对远端连接的效果）。

## 已有进展

通过 `.trae/specs/add-mcp-integration` 实施。`mcp.py` 的 `_build_single_connection()` 支持 stdio/http/sse 三种传输，http 映射为 `streamable_http` 键。`McpServerConfig` 包含 `url`、`headers` 字段。

## 剩余工作

- 补充 mock HTTP/SSE MCP 服务器的 E2E 测试（工具注册、调用、cleanup）。
- 验证 `close_all()` 对 HTTP/SSE 连接的清理效果。
