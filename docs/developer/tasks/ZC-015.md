## 范围

- 以 ZC-041 已验证、ZC-080 已解析的 Plugin catalog 替换仅有 `general-purpose` 的固定子 Agent 入口，同时保留 SDK `general-purpose` 作为受同一父策略约束的兼容兜底；Python 内置主 Agent 通过受控 `task`/delegation 工具按 Agent ID 发起同步子任务。主 Agent 不读取、也不允许由 Plugin AgentDefinition 替换。
- 每次 spawn 校验父 Agent 的 delegation enabled/allowedAgents/maxDepth/maxParallelism、目标 Agent 输入契约、合法 spawn 模型覆盖与有效 Policy。子 Agent 获得独立、最小化的任务上下文，不默认复制父 Thread 的全部消息、审批状态、隐藏 Prompt 或凭据。
- 每个 root/subagent execution 启动时固化 Agent ID、父 execution ID、有效模型、模型来源、Policy 指纹、深度与终态；将 child execution 追加到 ZC-082 的 canonical RunExecutionBinding 并在 root 终态 seal。单个 execution 一旦启动不可改变模型或 Policy，运行中的 `/model` 不影响它。
- 将取消、超时、失败、工具审批与结果汇总纳入同一 root run 生命周期；子 Agent 不得绕过 WorkspaceBoundary、Approval、Sandbox、MCP、ContextWindow 或 RuntimePool 约束。

## 非范围

- 不实现 Agent Team/Coordinator、预声明 Workflow、Mailbox、跨 Run 恢复队列、并行任意 fan-out、远端异步 Agent 或跨 Thread 通信。
- 不提供 TUI Agent Manager、`/agent` 选择、Agent/Policy 在线编辑、Agent 市场或模型自动选择；Agent 定向 `/model` 覆盖另行设计。
- 不允许子 Agent 反向提升父 Agent 权限、修改配置、修改 delegation 限制或读取工作区外/虚拟命名空间外的数据。

## 验收清单

- 主 Agent 可同步调用合法 Plugin 子 Agent；子 Agent默认使用自身 AgentDefinition 模型，只有合法的显式 spawn 覆盖才能替换它；ZC-078 的 Thread root 选择只影响内置根 Agent，且每次真实调用记录来源与脱敏模型摘要。
- 非法 Agent、未授权委派、深度/并发超限、无效输入、子 Agent 超时/失败/取消、审批拒绝、Runtime DRAINING 和 sidecar 重启均有确定终态，不泄漏上下文或重复执行工具。
- 一个 root Run 的调用树可正确表达父子关系和最终状态；不同 project/thread/run 的 execution 记录、上下文、工具事件和恢复信息不会交叉可见。
- Python mock 集成测试覆盖 catalog→spawn→结果汇总、权限交集、取消、execution tree seal 与 RunExecutionBinding；TypeScript 协议/事件显示保持兼容；用户/开发文档和项目级检查通过。
