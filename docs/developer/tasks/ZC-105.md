## 背景

Web 独占控制跨越 Bun server、浏览器 lifecycle、WebSocket attachment、Python Host、共享 Controller 和两个表现层。单元测试可以验证各 module，但不能证明 fragment 清理、真实 socket 关闭、窗口竞争、响应式布局和从 Web 返回 TUI 的最终结果。

本任务建立专用 Browser E2E，不新增产品能力。它是 ZC-101 至 ZC-104 的集成验收门槛，不能用人工现场操作或“build/test 通过”替代。

## 当前存在的问题

- 仓库没有 Playwright 依赖、配置、E2E script 或浏览器 fixture。
- 现有 gateway integration 默认 skip，且依赖真实进程路径，不覆盖 Web lifecycle。
- mock Coordinator 测试不能发现 bootstrap close handler 注册过晚、token 未撤销或 stale Thread 等跨进程竞态。
- 没有双视口、双主题截图和键盘/ARIA 验收，页面完成状态不可复现。
- 服务端生命周期规范要求的取消、中断/恢复、畸形帧和终态错误缺少完整集成覆盖。

## 为什么现在要修改

该功能的主要风险位于 module 之间。没有真实浏览器测试，任务文档中的“已完成”无法提供可审计证据，也无法防止 lifecycle 改动再次锁死 TUI。

## 目标设计

建立无真实凭据的 E2E fixture：

```text
Playwright
  → 启动测试 CLI/Bun Web server
  → 启动真实 Python AgentHost + 可控 fake Agent
  → 操作真实页面和 lifecycle WebSocket
  → 查询 Host/TUI 可观察状态
```

fixture 必须允许测试控制 fake Agent 的 streaming、Tool、approval、question、阻塞、取消和终态错误，同时保留真实 Protocol、attachment、Host、Controller 和页面代码。

测试分层：

- smoke：空首页、首条消息、流式回复和正常归还；
- parity：Thread、模型、Skill、MCP、compact、status、Slash Command 和 Interaction；
- lifecycle：第二窗口、ready timeout、bootstrap 断线、active Run 关闭、刷新和 CLI exit；
- security：fragment 清理、Origin/Host、token 单次/撤销、静态路径白名单、CSP 和 raw HTML；
- visual/a11y：1440×900、390×844，light/dark，键盘焦点、名称与状态。

## 实施步骤

1. 引入固定版本 Playwright 和独立 `test:web:e2e` script；浏览器安装/缓存方式写入开发工作流，不让普通 unit test 隐式联网。
2. 建立真实 Python Host + fake Agent fixture，提供确定的 Event、Interaction、阻塞和失败场景；禁止读取真实 API Key。
3. 提供测试专用 CLI/Web 启动入口和可观察 TUI lock/Host status seam；生产入口不得暴露测试控制能力。
4. 实现 smoke/parity 测试，验证所有用户可见能力和 TUI/Web semantic 一致性。
5. 实现 lifecycle 竞争测试，使用可控 barrier 精确覆盖 acquire 前后断线、ready timeout、active Run cancel、nullable Thread 归还和 CLI exit。
6. 实现安全测试：错误 Host/Origin、重复 token、revoke 后认证、路径遍历、非白名单资源、fragment 清除和 Markdown raw HTML。
7. 生成并审查四组基线截图；断言 viewport 内无横向溢出、主要控件不重叠且可通过键盘访问。
8. 补齐 Protocol/Host 的畸形帧、终态错误和取消/恢复回归，运行项目级检查。
9. 更新用户/开发文档；各任务只在代码、自动化证据、文档和关联提交/PR 均存在后标记完成。

## 范围

- Playwright 配置、fixture、E2E 用例和受控截图。
- 真实 Protocol/Host/Browser 集成，不使用真实模型。
- Web 安全、生命周期、功能 parity 和视觉/可访问性验收。
- 完成状态、文档与证据检查。

## 非范围

- 不新增 Web 产品功能或重新设计共享 Controller。
- 不测试真实第三方模型、MCP server 或企业认证。
- 不要求所有 unit test 通过浏览器运行。
- 不把人工截图或一次性现场操作作为唯一证据。

## 验收清单

- [ ] `test:web:e2e` 可在干净环境中使用 fake Agent 重复运行，不读取模型凭据。
- [ ] 空状态首条消息、完整 Timeline、Interaction、取消、Thread/catalog/command parity 有真实浏览器覆盖。
- [ ] 第二窗口、acquire 前后断线、ready timeout、`/new` 后归还、active Run 标签页关闭和 CLI exit 均收敛到正确 holder/Thread。
- [ ] fragment 在 bootstrap 后清除；错误 Origin、重复/撤销 token 和非白名单静态路径被拒绝。
- [ ] 1440×900 与 390×844 的 light/dark 截图稳定，页面无横向溢出、重叠或不可达主要操作。
- [ ] 键盘可完成发送、命令选择、Interaction、面板关闭和返回；交互控件具备可访问名称与状态。
- [ ] `bun run build`、`bun run typecheck`、`bun run test`、`bun run project:check` 和 Browser E2E 全部通过。
- [ ] ZC-101 至 ZC-105 的测试证据、文档影响、版本影响和关联提交/PR 均已记录后才标记完成。
