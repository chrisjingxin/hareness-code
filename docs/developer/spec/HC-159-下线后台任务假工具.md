# Spec: HC-159 下线后台任务假工具

> 链接回 Task：docs/developer/task/HC-159-下线后台任务假工具.md

## 目标

移除模型可见的 monitor、task_output、task_stop 三个未实现工具及其全部静态引用，使工具面只包含真实能力。

## 现状 interface（将被删除）

| 工具 | 声明行为 | 实际行为 |
| --- | --- | --- |
| monitor(command, interval) | 后台持续执行命令 | 仅在内存字典登记，返回假"已启动" |
| task_output(task_id) | 获取后台任务输出 | 永远返回空输出 |
| task_stop(task_id) | 终止后台任务 | 只翻转字典标志位 |

## 删除后的目标状态

- `create_harness_tools()` 返回集合不含三个名字；`BackgroundTaskManager` 类与 `tools_mode.py` 模块整体删除；
- `_BUILTIN_TOOL_SHAPES` 契约不含三个名字；
- 策略面收敛为单工具语义：
  - `SHELL_TOOLS == {"execute"}`、`DELEGATION_TOOLS == {"task"}`；
  - 审批 HITL 集合、`_PLAN_ALLOWED_TOOLS`、ToolKind 映射、并发只读集合、execution_stream 并发安全集合、deferred 名单、ALL_TOOL_NAMES、CLI 展示目录均不含三个名字。

## 错误语义

规则 DSL 解析器删除 `KillShell → task_stop` 映射后，`KillShell` 属于未知工具名：按既有语义 fail-closed 进入 EXECUTE 风险类别，规则不再精确生效但安全性不降低。

## 不变式（invariant）

**工具名唯一事实源**：一个内置工具名要么同时存在于工具注册、工具契约、策略分类与展示目录，要么全部不存在。测试以负向断言锁定"全部不存在"这一侧。

## 可观察验收

1. `cd packages/agent && .venv/bin/python -m pytest -q` 全绿；
2. `cd packages/cli && bun test` 全绿；
3. 活跃代码/测试/用户文档中 grep 三个工具名无命中（历史存档除外）；
4. 负向测试存在：test_harness_tools / test_deferred_tools / test_subagents_tools / tool-display-policy.test.ts。

## 非范围

同 Task 非范围。不新增后台任务能力；不动插件 Monitor 机制。
