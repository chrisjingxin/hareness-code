# 新功能候选

本文只留存产品与平台方向，不是任务看板，也不表示优先级、承诺或实施顺序。架构 P0 收敛完成并重新梳理产品目标前，不从这里直接认领实现。

## 多前端与交互体验

- 多题审批/问答表单，以及更完整的 Interaction 展示。
- Context Inspector、引导式压缩、诊断面板、Settings/Permissions、MCP/Tools、Skill Manager。
- Thread 重命名、删除、导出、保留策略、Timeline、Fork、Rewind。
- Agent 变更 checkpoint、diff、undo/redo、usage、history 和复制。
- TUI 主题、动画、终端兼容与输入偏好。
- active Run replay、断线恢复和动态 Command reload。
- TUI 右侧 Sidebar：Thread / 工作区 / 上下文占用 / 模型 / Skill 等弱状态面。HC-145 明确不做。
- TUI Compose 阶段顶栏：理解 / 规划 / 实现 / 验证 / 复审与当前任务。HC-145 已从对话页卸下，后续单独拆 Task 重做，不要直接把旧 `WorkItemView` 挂回去。
- TUI 进入 Subagent 子对话（从 `task` 摘要钻进 child Timeline）。
- TUI Skill 专用卡、Plugin 自定义 Tool Renderer、独立 StructuredOutput 卡。
- Thread 恢复时按条保留 Run Mode（需 Transcript / `threads.open` 补字段）。HC-145 只保证当场会话按条记住，恢复退回 `threadMode`。

## Agent 与扩展体系

- 受信任的 AGENTS.md 记忆来源和项目上下文摘要。
- Plugin 安装、来源校验、Agent/Policy catalog 接入与同步或远端 Subagent。
- 固定 Workflow、Agent Team、Mailbox 与受控并发编排。
- Agent 定向模型选择、第二类 Provider 和跨 Provider canonical message。
- 目标与验收标准驱动的长任务闭环。
- Agent 前后端工程模板生成。

## MCP、工具与企业能力

- HTTP/SSE MCP、OAuth、项目 MCP 指纹信任和 MCP 管理界面。
- 企业远端 Sandbox Provider、审计事件与遥测 adapter。
- 可信项目配置、managed policy、Hooks、Extensions 和企业 Plugin 源。
- 危险 Unicode 风险提示、受保护的 AGENTS.md 管理区块。
- 带 SSRF 防护的网页读取工具。

## 分发与工程条件

- macOS、Linux、Windows 自包含运行包与安装器。
- 企业 DeepAgents、MCP adapter 依赖升级。

重新启用某个方向时，应先确认产品目标、用户流程和安全边界，再拆成新的独立任务，不恢复旧任务文件。
