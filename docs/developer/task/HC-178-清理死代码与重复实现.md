# HC-178 清理死代码与重复实现

需求已用 `grilling` 与用户确认（2026-09-10）。用户结果与验收以本文为准。后续 Spec / Plan / Todo 只能细化本范围，不能把「明确不做」清单里的项做进来。

## 通俗说明

仓库里同时活着几套已经没人走的实现，和几套名字不同、干同一件事的代码。读代码的人分不清哪条是真路径，也容易在死代码上继续加功能。

本任务只做三件事：

```text
删掉生产路径碰不到的代码
  → 合并仍在跑、但重复的 Skill / 资源租约
  → 改掉还在撒谎的过期文档
```

用户在终端里看到的 Build、Compose、审批、插件行为必须和现在一样。变短的是维护面，不是产品面。

## 当前问题

1. HC-138 的 `ComposeWorkflow` 和状态机还在树里，生产走的是 HC-155 的 `ComposeSession`。
2. `extensions/skills.py` 与 `plugin_skills.py` 各有一份 `SkillRegistry` / `SkillMarketplaceProvider`，Host 两边都 import。
3. `resource_lifecycle.py` 与 `resource_ownership.py` 两套租约，枚举值还不一致。
4. CLI 仍有 `options.agent`、`createFallbackNoopGateway` 等兼容入口；规范禁止无主兼容。
5. 若干文档仍写 JSON-RPC v2、`Session`，或把已归档的 HC-092..097 当成当前 P0。

## 已确认决策

1. **一份 Task**，内部按停点推进，不拆成平级清理 Task。
2. **零用户可感知行为变化。** 不改协议、SQLite schema、公开 interface、错误语义。
3. **现任 Task 的活不抢：** Work Item 引擎归 HC-155；TUI `file-icons.ts` 归 HC-152；迁移仪式和拆 `thread_persistence.py` 归 HC-108。
4. **拆上帝文件不进本任务：** `AgentHost`、`settings.py`、TUI/Web adapter 只读不拆。
5. **明确不做必须写进 Todo 冻结清单**，执行时不得勾选推进或「顺手做掉」。

## 用户最终得到什么

开发者和后续 Agent 打开仓库时：Compose 旧工作流、重复 Skill 类型、重复资源租约和兼容别名不再挡路；文档与代码一致。最终用户的操作路径不变。

## 范围

1. 删除生产零引用、且不属于进行中 Task 的代码与其测试：`ComposeWorkflow` 栈、生产 `createFallbackNoopGateway`、仅被自身测试引用的 `semantic-tone.ts`、过时 `evaluations/zc133/`、重复的 `test_hc166_plugin_management_red.py`、已完成的 `migrate-docs-layout.ts`。
2. 拆除无主兼容别名：`options.agent` / `options.runtime`、`InteractiveScheduler`、`InteractiveResult`、`agent-port.ts` 转发、`ALWAYS_SAFE_COMMANDS` 旧并集、`ask→default` 若已无调用方、Host 测试包装函数。
3. 合并两套 Skill 运行时为一个模块；市场 Protocol 若无企业包实现则不单独保留第二份拷贝。
4. 合并两套共享资源租约为一个 owner+lease；统一 `ResourceScope` 枚举。
5. 纠正过期文档：根目录 `tasks/`、两份项目分析、把已归档任务写成当前待办的 `架构重构计划.md`；架构总览如有与代码不符的过期表述一并改。
6. 在 Todo 中冻结「本任务明确不做」清单，完整保留到归档。

## 非范围

下列项**不是本任务的工作**，详见 [Todo 冻结清单](../todo/HC-178-清理死代码与重复实现.md)。摘要：

- 删除 `ComposeWorkItemEngine` 及 activities / work_item SQLite（HC-155）。
- 删除或接线 TUI `file-icons.ts`（HC-152）。
- 收敛 legacy 迁移 child / poison / 拆 `thread_persistence.py`（HC-108）。
- 拆 `AgentHost`、`settings.py`、TUI/Web adapter。
- 收薄执行栈四层、绑定名堆、Selector 切片、`getGateway()` 绕过 Core。
- 删 `RemoteSandboxFactory`、换掉 lucide-react、合并 TUI Tree-sitter 与 Web Shiki、大合并 Policy 文件。

## 可观察验收

1. 生产代码不再 import `ComposeWorkflow` / `ComposeStateMachine`；对应测试已删或改为只覆盖 Session。
2. `SkillRegistry` 与 `SkillMarketplaceProvider` 只在一个模块定义；Host / runtime / 测试只从这一处导入。
3. `SharedResourceOwner` / `SharedResourceHandle` 只留一套；`ResourceScope` 枚举值唯一。
4. `createInteractiveController` 必须注入 `gateway`，不再 fallback 到 noop；`options.agent` 编译期不存在。
5. `docs/项目分析.md`、`docs/Harness-Code-项目深度分析.md`、根 `tasks/` 不再把 v2 / Session / 已归档 P0 写成现状。
6. 相关 focused tests 与包级检查通过；`bun run typecheck` 通过。
7. Todo「本任务明确不做」一节仍在，且 git diff 不包含那些路径上的「顺手重构」。
