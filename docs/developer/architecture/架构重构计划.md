## 已落地基础

HC-085～HC-091、HC-093～HC-094 已完成，当前生产路径已经具备：

- 模型选择与 Run 执行绑定的统一解析；

这些 task 的完整背景、验收证据和历史实现记录保留在任务归档目录，不再出现在活动看板或当前计划链接中。

## 已完成的目录重构

HC-098、HC-099、HC-100 已完成，目录职责与 canonical import 已固定：

- Python Agent 按 `host/runtime/threads/config/policy/tools/extensions/protocol` 分层，Connection 与 WebSocket attachment 独立于 `AgentHost`；生成的 Protocol 与 Prompt 资源随 wheel 分发。
- CLI TUI 按 `application/presentation/platform/upstream` 分层，`app.tsx` 只负责 OpenTUI 组合；Presentation 不直接依赖 IPC，Web launcher 归入 `src/web/`。
- 开发文档按 `architecture/project/research/tasks` 分层，历史快照进入 `research/archive/`；项目任务、文档和发布检查拆到 `scripts/project/`。

这些任务只改变内部路径和职责边界，不改变 JSON-RPC v3、CLI 命令、配置格式或版本号。
