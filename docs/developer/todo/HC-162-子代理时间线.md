## 停点 1：TUI 能点进去看

用户怎么看：`bun run dev`，派 `general-purpose` 做会调工具的事。主时间线只有派出卡。点卡进入子时间线，能看到它自己的工具；Esc 回到派出卡。

- [x] 协议：`tool.delta` payload 增加可选 `child_execution_id`、`child_agent_id`。`bun run protocol:generate && bun run protocol:check`。
- [x] 运行时：Inline child 走 ExecutionStream，事件信封填 child `execution_id` / `parent_execution_id` / `agent_id`。删除生产 child `ainvoke`。focused：至少一次 child `tool.started` 带 child 身份。
- [x] 绑定：Delegator 创建 child 后，对父 `task` 的 `tool.delta` 写入绑定字段。两个并发 `task` 不串。
- [x] Transcript：非 root `execution_id` 的过程事件不写入父 Transcript。测试：持久化后主上下文不含 child `read_file` 正文。
- [x] Interactive Core：`ToolCard.childExecutionId` / `childAgentId`；`scopeTimeline(items, executionId)`。父视图过滤 child 项。
- [x] Intent：`open-child-timeline` / `leave-child-timeline`。child route 下拦截发送。
- [x] TUI：派出卡可点；子视图只读渲染该切片；Esc/返回离开；审批 Dock 仍在。`views.test.ts`：父帧无 child 工具名，进入后有，返回后派出卡仍在。
