用户怎么看：`bun run dev`，输入 `/agents`，应列出 `general-purpose`、`explore`（以及已启用 Plugin），并标明来源和工具边界。对主 Agent 说「用 explore 搜索 task 工具的定义位置」，应得到路径/符号，且不改仓库、不弹写文件审批。

- [x] 协议：`agentSummary` 增加必填 `kind`（`builtin` \| `plugin`）和 `tools`（string[]）。运行 `bun run protocol:generate && bun run protocol:check`，TS/Python 类型与 fixtures 一致。
- [x] 内置定义：新增本仓库中文 description、系统提示词、工具上限与 Forced exclusions（Spec 7）。`explore.tools` 为五只读名；`general-purpose.tools` 为空数组表示继承父能力再减排除项。fingerprint 含提示词 digest。
- [x] Catalog：`AgentCatalog.list_agents()` / `require_agent` 先放入两个 builtin，再合并已启用 Plugin。Plugin 占用 `main` / `general-purpose` / `explore` 时忽略并写 diagnostic。`agents.list` / `agents.inspect` 走同一摘要。
- [x] 生产 `task`：`_create_controlled_inline_subagents` 同时注册 `general-purpose` 与 `explore`（及 Plugin Managed）。description 用内置中文，不再用 DeepAgents 英文。执行前按当前 catalog 解析，未知 ID → `DELEGATION_TARGET_NOT_FOUND`。
- [x] explore Inline 子图：工具求交后只剩只读集合；无 MCP / `tool_search` / Shell / `task`。系统提示不含 Skill 索引。新对话只有 task 文本。写工具由能力视图拒绝。未拆独立 filesystem backend（Skill 虚拟路径若已知仍可能被 `read_file` 读到，停点 3 前可再收）。
- [x] GP 本停点：套 Forced exclusions，继承父 Skill 索引与 MCP。HITL 松紧不动（停点 2 再改）。
- [x] CLI：`/agents` 打开只读浏览浮层（TUI/Web），列出内置 + Plugin，标明 kind 与工具边界；选中不切换当前 Agent。
- [x] 聚焦测试：`tests/runtime/test_builtin_agents.py` 5 passed；catalog / delegation / host list 回归通过；CLI `commands` / `protocol-contract` / `client` 43 passed。`bun run protocol:check` 通过。

## 停点 2：GP 审批语义与 Interaction 队列

用户怎么看：审批模式 default。派 `general-purpose` 改一个普通工作区文件：派出可能弹一次 `task`，确认后文件写入不再弹窗，时间线能看出子代理在写。再派它跑一条 `execute`：底部出现「子代理 general-purpose 需要审批」；拒绝后对话还在。父正在 `ask_user` 时 child 的命令审批应排队，不能把提问卡丢掉。

- [x] 实现 Spec 8.1：`resolve_child_approval_mode(parent, role)`。仅 `general-purpose` + 父 `default` → child `auto-edit`；其余等于父模式。Plugin 不走此函数放宽。
- [x] GP Inline 子图按 child 模式挂 ChildHitlMiddleware / PlanModeMiddleware / deny。工作区非敏感写不弹窗；`execute`、敏感路径、目录信任走 Host Interaction，params 含 `agent_id` / `execution_id` / `parent_execution_id`。
- [x] 派出 `task`：explore 只读视图成立则自动通过；GP 在 default 下审批，描述含「可在工作区改文件，普通写入过程中不再询问；执行命令和敏感路径仍会询问」。
- [x] CLI/Web：`InteractiveInteraction` 增加 `agentId`；Approval/DirectoryTrust Dock 标题使用它。`InteractionFeature` 改为 FIFO 队列：新请求入队，禁止替换旧请求。
- [x] 拒绝结果回到原 child tool result，不取消父 Run。dynamic deny 在 child 入口仍拦截。
- [x] Plugin：需要 Interaction 仍 `MANAGED_AGENT_INTERACTION_UNAVAILABLE`。测试：伪造 Plugin `permissionMode: yolo` 不得写入更松审批。
- [x] 聚焦测试：`test_child_approval.py`、`test_builtin_agents.py` 审批模式；CLI `interaction-feature` FIFO + agentId 标题。
