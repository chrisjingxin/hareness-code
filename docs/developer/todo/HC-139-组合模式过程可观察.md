## 使用规则

- 按步骤顺序执行；只有明确标注可并行的 renderer 工作可以并行。
- 每个步骤使用 `agent-skills:test-driven-development`，先让新增测试因缺少目标行为而失败，再写最小实现。
- 一个执行 Thread 完成一个步骤或一个明确 renderer 分支；交接只记录当前 Todo、未提交改动和验证状态，不复制 Task/Spec/Plan。
