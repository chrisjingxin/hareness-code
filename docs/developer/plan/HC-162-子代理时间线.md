# HC-162 子代理时间线实施计划

关联任务：[Task](../task/archive/HC-162-子代理时间线.md) · [Spec](../spec/HC-162-子代理时间线.md) · [Todo](../todo/HC-162-子代理时间线.md)

不新增范围。一次只做到下一个可演示停点。

## 通俗怎么拆

原有停点 1/2 已实现 Inline child 和双端路由；2026-09-03 真实 ZA38 验收证明 Managed Plugin child 的过程仍被 observer 丢弃。本次不重做前两段，只增加一个联合返修停点，一次打通 Managed 运行时与 TUI/Web 空态。

```text
停点 1  过程能流出来，TUI 点派出卡进入只读子时间线
  │
停点 2  Web 同一套交互 + 用户文档
  │
返修停点 3  Managed Plugin child 过程可见 + 双端空态
```

父子过滤、绑定、流式替换 `ainvoke` 必须和 TUI 进入做在同一步，否则用户看不见。

## 已锁定的做法（不在实现时重开）

- 不新开 Event type；用现有信封 `execution_id` / `parent_execution_id` / `agent_id`。
- `tool.delta` 增加 `child_execution_id` / `child_agent_id`，一对一绑到父 `task`。
- 父视图过滤掉 child execution 项；子视图只渲染该 execution。
- child 过程不进父 Transcript。
- 子视图只读；审批仍在主会话 FIFO。
- 不做 Prev/Next 循环、不做历史恢复重建、不改 300s 超时。

## 停点 1 — TUI 能点进去看

**改什么：** Inline child 改为 ExecutionStream（或等价 astream），事件带 child 身份。父 `task` 在 child 创建后 `tool.delta` 带绑定字段。CLI reducer 写入 `ToolCard.childExecutionId`。`scopeTimeline` 切父/子。TUI：点派出卡 `open-child-timeline`，Esc/返回 `leave-child-timeline`，Composer 禁用。审批 Dock 在子视图仍显示。

**为什么：** 当前痛点是闷跑。TUI 是用户截图所在界面，先打通这一条才算可看。

**怎么验证：**

```text
bun run protocol:generate && bun run protocol:check
cd packages/agent && .venv/bin/python -m pytest -q tests/runtime/test_builtin_agents.py tests/runtime/test_child_approval.py tests/runtime/test_agent_delegation.py
cd packages/cli && bun test tests/interactive tests/tui/presentation/views.test.ts tests/presentation-shared
```

断言：child `read_file`/`execute` 事件带 child `execution_id`；父 Transcript 没有这些正文；TUI 父帧没有这些工具名，点卡后有。

**可演示：** `bun run dev`，派 `general-purpose` 做一件会调工具的事。主时间线只有派出卡。点进去能看到它正在用的工具；Esc 回到派出卡。若弹出「子代理 … 需要审批」，在子视图里也能处理。

## 停点 2 — Web 对齐与文档

**改什么：** Web Adapter 实现同一 Intent；派出卡可点；子时间线只读；返回按钮。用户文档（`交互使用.md`、`subagent.md`）写进入/返回。架构总览补一句：child 过程事件只给 UI 投影，不进父 Transcript。

**为什么：** Task 要求两端同一套交互；没有文档用户不知道能点。

**怎么验证：**

```text
cd packages/cli && bun test tests/web/presentation tests/web/application
bun run typecheck
```

**可演示：** 同一派出，Web 点卡片进入子时间线，返回后主时间线仍只有派出卡。文档能按步骤做一遍。

## 风险

| 风险 | 处理 |
|---|---|
| DeepAgents 子图 astream 与父 HITL 抢 interrupt | child 继续走 ChildHitlMiddleware + Host Interaction，不把 LangGraph interrupt 冒泡到父 ToolNode |
| 两个 task 并发绑错 | 只按父 tool_call_id 绑定，禁止按 agent_id 猜测 |
| 过程事件误写入 Transcript | 持久化入口按 execution_id 丢弃非 root；加测试 |

## 返修停点 3 — Managed Plugin child 真实可观察

**改什么：**

- 在 Managed executor 边界提供专用 child observer：保留 `capture_only` 与 `observe_message=False`，但把 tool/reasoning signal 透传到父 Run `event_port`，并在完成时把最终文本投影到 child execution。
- `AgentHost` 从同一 delegation call 冻结 parent event port、child ref 和 agent id，不改 Delegator 绑定规则、Plugin 权限交集、SubagentStop 或审批语义。
- TUI/Web 在 child route 为空时显示专用空态，不再呈现成清屏或“发送第一条消息”。
- 不修改 Protocol schema，不持久化 child timeline，不把 child 过程写入父 Transcript。

**实现顺序：**

1. 先用 fake graph 写 Managed Plugin 纵向失败测试，证明当前只有 binding/result，没有 child tool/reasoning Event。
2. 实现 observer 与 Host 绑定，使同一测试变绿；再验证 Transcript 隔离、取消/超时、SubagentStop 和 Interaction fail-closed 不回归。
3. 先写 TUI/Web 空态失败测试，再实现共享判断与两端文案；最后跑原 Inline child 和 HC-166 Plugin 启动回归。

cd packages/cli && bun test tests/interactive/child-timeline.test.ts tests/presentation-shared/timeline-scope.test.ts tests/tui/presentation/views.test.ts tests/web/presentation/timeline.test.tsx

**联合可演示停点：** 用 ZA38 Extension 派出 `za38-frontend-executor` 执行一次必然调用工具的离线/本地任务。运行中点卡片能看到工具起止，结束后仍有过程和最终文本；Esc/返回后主时间线完整。如果刚绑定尚未有事件，TUI/Web 都显示明确 child 空态。到此停止，不提交、不推送，等待主任务和用户验收。
