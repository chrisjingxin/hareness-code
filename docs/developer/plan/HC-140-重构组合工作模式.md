关联任务：[HC-140](../task/HC-140-重构组合工作模式.md)

执行清单：[HC-140 Todo](../todo/HC-140-重构组合工作模式.md)

## 文档职责

- Task 是用户结果、范围和整体验收事实源。
- Spec 是 interface、状态、错误、存储、安全和 invariant 事实源。
- 本 Plan 只安排真实依赖、纵向工作包和验证检查点，不新增范围。
- Todo 与工作包一一对应；实施发现需要决定新的协议、状态、目录、权限或恢复语义时，先停止并修订 Task/Spec/Plan/Todo。
- HC-140 直接替代 HC-138 的固定 ComposeRun canonical 路径；实施期间可以先构建未接线 module，但生产入口切换时必须一次删除旧路由，不能发布双写或 fallback。

## 交付概览

```text
基础资产
├─ 原版内置 Skill bundle
└─ ManagedAgentExecutor
      ├─ Build parity
      ├─ Plugin Agent 迁移
      └─ Compose Activity 迁移

Work Item 核心
├─ Thread mode + Work Item SQLite
├─ Workspace Markdown + readiness
├─ Turn intent + lifecycle
└─ effect receipt + restart recovery

纵向 Compose 流程
├─ Task gate
├─ Spec gate
├─ Plan/Todo gate
├─ Implement
└─ Verify → Review → Report → Complete

产品接入
├─ Protocol / Host
├─ Interactive Core / Command Registry
├─ TUI / Web
└─ E2E / 删除旧实现 / 文档闭环
```

## 风险与缓解

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| ManagedAgentExecutor 过度抽象 | Build/Plugin/Compose 都被复杂 interface 绑住 | 先用 Build + Plugin 两个真实 adapter 固定最小 interface；只支持已存在输出策略 |
| 原版 Skill 过长影响弱模型 | Activity 超 context 或指令冲突 | 首版按用户决定保留原文；使用 fresh Activity、小 ContextPack、固定路径覆盖并记录 token/失败指标，优化另开 Task |
| Markdown 与 SQLite 冲突 | 恢复错误或覆盖用户编辑 | 正文只信 Markdown，执行事实只信 SQLite；digest mismatch 只失效，不反向覆盖 |
| Tool 崩溃后 outcome unknown | 重复副作用 | intent/receipt + adapter reconcile；未知必须 blocked + 用户决定 |
| Mode/Work Item 并发竞态 | 两个 active 或 Run 绑错目标 | ThreadPersistence `BEGIN IMMEDIATE` + unique/CAS + Run binding fingerprint |
| 旧 Compose 大量测试耦合阶段枚举 | 改造被兼容层拖住 | 以新 interface/行为测试替换，生产切换时删除旧测试和实现，不保留 alias |
| TUI/Web 各自解释命令 | 可见性和确认行为漂移 | Command Registry、Selector、IntentOutcome 单一事实源，renderer 只展示 |
| 任务规模过大 | 中途形成不可用混合状态 | WP1～WP15 小步纵向验证；Checkpoint A/B/C 强制 Review；最终原子 cutover |
